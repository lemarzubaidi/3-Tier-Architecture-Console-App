# Contact Management System

A C# Console Application for managing contacts and countries using a 3-Layer Architecture with SQL Server and ADO.NET.

## Features

- Add, update, delete, and find contacts
- List all contacts
- Check whether a contact exists
- Manage countries by ID or name
- Add, update, delete, and list countries
- Store contact details including email, phone, address, date of birth, country, and image path
